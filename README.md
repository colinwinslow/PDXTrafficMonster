# PDXTrafficMonster

An animated data visualization of how Portland traffic redirects during the
five-week closure of I-5 southbound through the Rose Quarter (closed
2026-09-11, reopening expected mid-October 2026), built on real public
traffic data — not a simulation.

## Status

Phase 0 — research and framing. See [`STATUS.md`](STATUS.md) for current
state and [`docs/research/i5-closure-data-sources.md`](docs/research/i5-closure-data-sources.md)
for the data-source survey this project is built on.
